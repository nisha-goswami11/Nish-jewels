# 💎 Nish Jewels

A modern and elegant jewellery e-commerce website designed to showcase beautiful jewellery collections including rings, necklaces, earrings, and bracelets.

🔗 **Live Website:** https://nish-jewels-nine.vercel.app/

---

## ✨ About The Project

**Nish Jewels** is a front-end jewellery shopping website created to provide a simple, elegant, and user-friendly online shopping experience.

The website allows users to explore different jewellery categories, view products, add items to their cart or wishlist, and proceed through the checkout process.

This project was created as a web development project to practice and demonstrate skills in **HTML, CSS, and JavaScript**.

---

## 🌸 Features

- 🏠 Attractive Home Page
- 💍 Jewellery Categories
